# Campuly REST API v1 (Phase 3 specification)

Base URL: `https://<host>/api/v1` · JSON only · UTF-8 · HTTPS only in production.

## Authentication

- `POST /api/v1/auth/login` `{ email, password, device_name }` → `{ token, user }` (2FA challenge when enabled: `{ two_factor_required: true }` then `POST /auth/two-factor`).
- Header: `Authorization: Bearer <token>`. Tokens are Sanctum personal access tokens, one per device, listed and revocable in the profile page.
- `POST /auth/logout` revokes the current token. `GET /me` returns user, roles, schools, current period, locale, permissions summary.

## Conventions

| Topic | Rule |
|---|---|
| Language | `Accept-Language: fr` or `en`; responses and errors translated |
| Envelope | `{ "data": …, "meta": {…}, "links": {…} }` |
| Pagination | `?page[size]=50&page[cursor]=…` (cursor-based), max 200 |
| Filtering | `?filter[class_id]=…&filter[status]=active` |
| Sorting | `?sort=-created_at,name` |
| Includes | `?include=guardians,enrolment` (whitelisted per resource) |
| Ids | Public ids are ULIDs (`uuid` column); numeric ids never exposed after Phase 3 |
| Money | `{ "amount": 125000, "currency": "XAF", "formatted": "125 000 FCFA" }` |
| Dates | ISO 8601 with offset; `date` fields `YYYY-MM-DD` |
| Errors | RFC 9457 `application/problem+json`: `type`, `title`, `status`, `detail`, `errors` (validation) |
| Rate limit | 120 req/min per token (auth: 10/min per IP); headers `X-RateLimit-*` |
| School context | Header `X-Campuly-School: <school ulid>`; period via `X-Campuly-Period` (defaults to current) |
| Idempotency | `Idempotency-Key` header on all `POST` that create money or records |

## Resource plan

| Area | Endpoints |
|---|---|
| Context | `GET /schools`, `GET /schools/{id}/periods`, `GET /academic-years` |
| Structure | `GET /classes`, `/sections`, `/subjects`, `/course-offerings` |
| People | `GET/POST/PATCH /students`, `GET /students/{id}`, `/staff`, `/parents` |
| Attendance | `GET /attendance/registers?date=&section=`, `PUT /attendance/registers/{id}` |
| Gradebook | `GET /gradebook/mark-sheets?course_offering=`, `PUT /gradebook/mark-sheets/{id}/marks` |
| Timetable | `GET /timetables/week?section=|teacher=` |
| Finance | `GET /invoices`, `GET /invoices/{id}`, `POST /payments`, `GET /payments/{id}/receipt.pdf` |
| Mobile money | `POST /payments/mobile-money` (request-to-pay), `GET /payments/{id}/status`, webhook `POST /webhooks/payments/{provider}` |
| Notices, calendar | `GET /notices`, `GET /calendar-events` |
| Library | `GET /library/titles`, `POST /library/loans`, `POST /library/loans/{id}/return` |
| Portal | `GET /portal/children`, `GET /portal/children/{id}/{results|attendance|timetable|invoices|notices}` |
| Reports | `GET /reports`, `POST /reports/{type}/runs`, `GET /reports/runs/{id}/download` |
| Sync | see `OFFLINE_SYNC.md` |

## Testing rules

Every endpoint: one success test, one validation test, one forbidden test **per role that must not access it**, one cross-school isolation test.

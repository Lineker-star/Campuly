# Campuly brand guidelines

## 1. Identity

| | |
|---|---|
| Name | **CAMPULY** (uppercase in the wordmark; "Campuly" in running text) |
| Tagline (EN) | **Learn · Interact · Excel** |
| Tagline (FR) | **Apprendre · Interagir · Exceller** |
| Promise | One place where a school learns, interacts and excels — online or offline, in English or French. |
| Personality | Clear, modern, warm, trustworthy, African and international |

The **mark** combines a graduation cap (education), a **C** (Campuly, campus), a **play button** (learning content, interaction) and an **orbit swoosh** (connection, movement, excellence).

## 2. Logo files (`public/img/brand/`)

| File | Use |
|---|---|
| `campuly-logo.png` | Full lock-up (mark + CAMPULY + tagline) on light backgrounds: sign-in, installer, documents, website |
| `campuly-logo-dark.png` | Same, white wordmark, for dark backgrounds |
| `campuly-mark.png` | Mark alone (transparent): sidebar, header on mobile, small spaces, PDF headers |
| `icon-16 … icon-1024.png`, `favicon.ico`, `apple-touch-icon.png` | App icon (rounded tile) for browsers, PWA, desktop installers, stores |
| `maskable-192.png`, `maskable-512.png` | Android adaptive icons (safe zone respected) |
| `campuly-logo-source.png`, `campuly-app-icon-source.png` | Original artwork as supplied — keep, never edit |

In code always use `<x-brand-logo variant="mark|inline|full" />`; it switches light/dark automatically.

**Clear space:** keep empty space around the logo at least the height of the "C" bowl. **Minimum size:** full lock-up 140 px wide on screen (tagline must stay legible), mark 20 px, app icon 16 px.

**Don't:** stretch, rotate, recolour the mark, add shadows/outlines, place the light logo on busy photos, change the font of the wordmark, translate the name.

## 3. Colours

| Token | Hex | Role |
|---|---|---|
| Navy | `#0B135A` | Wordmark, headings in brand moments, dark surfaces |
| Blue | `#0044FB` | Gradient start, highlights |
| Indigo | `#2E2CFC` | **Primary** — buttons, links, focus, selected states |
| Violet | `#7109FC` | Accent — "LY", badges, secondary charts |
| Purple | `#A100F8` | Gradient end, celebratory accents |
| Brand gradient | `linear-gradient(135deg, #0044FB 0%, #2E2CFC 45%, #7109FC 80%, #A100F8 100%)` | Primary buttons, progress, hero areas, PDF header line |

Neutrals are tinted towards indigo (see `DESIGN_SYSTEM.md`). Status colours: success `#16A34A`, warning `#D97706`, danger `#DC2626`, info `#0284C7` — never use brand violet to mean "error" or "success".

Contrast: white text on Indigo ≈ 7.3:1 and on Violet ≈ 6.6:1 (AA and AAA for large text). Navy on white ≈ 16:1.

## 4. Typography

- **UI and documents:** Plus Jakarta Sans Variable (self-hosted, works offline). Weights 400 body, 500 labels, 600 headings, 800 wordmark text.
- **Numbers:** tabular figures in tables, stat tiles and money.
- **Scale:** 12 / 14 / 16 / 18 / 22 / 28 / 36 px.

## 5. Voice

- Speak to busy school staff and parents: short sentences, verbs first ("Record payment", « Enregistrer le paiement »).
- Same meaning in both languages, not word-for-word translation; follow `GLOSSARY_EN_FR.md`.
- Respectful, never childish; celebrate progress ("All registers taken today — well done").

## 6. Applications

- **Sign-in / installer:** full logo centred on a soft brand aurora background.
- **App shell:** mark + CAMPU**LY** wordmark + tagline in the sidebar; mark only when collapsed or on mobile.
- **PDFs:** school logo on the left (if set), Campuly mark small in the footer "Generated by Campuly", 3 px brand-gradient line under the header.
- **Emails:** full logo header (light), indigo buttons, footer tagline in the recipient's language.
- **PWA / desktop:** app icon tile; splash background `#F7F8FF`, theme colour `#2E2CFC` (light) / `#0B135A` (dark).

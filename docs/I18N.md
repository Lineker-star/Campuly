# Internationalisation — English ⇄ French

Goal: **every word** in Campuly can be shown in English or French, chosen per user, switched instantly.

## 1. Where translations live

| File | Content |
|---|---|
| `lang/en.json`, `lang/fr.json` | UI sentences, keyed by the English text (`__('Record payment')`) |
| `lang/{en,fr}/enums.php` | Enum labels: `__('enums.feature.attendance')` |
| `lang/{en,fr}/validation.php` | Validation messages + `attributes` (field names) |
| `lang/{en,fr}/auth.php`, `passwords.php`, `pagination.php` | Laravel defaults |
| `lang/{en,fr}/mail.php`, `sms.php`, `pdf.php` | Message templates and document labels |
| `resources/js/i18n.js` + JSON injected in the layout | JavaScript strings (`t('Offline')`) |

Already present after the rebrand: tagline, sign-in description, installer title, maintenance message.

## 2. How the language is chosen

`?lang=` → session → user's `locale` → school default → installation default → browser `Accept-Language` → `APP_DEFAULT_LOCALE` (fr). Set in `SetApplicationLocale` together with Carbon and number locales (`fr_CM`, `en_CM`). Emails, notifications, SMS and PDFs use the **recipient's** language (`HasLocalePreference`).

## 3. Rules for developers

1. Never write a visible literal. Blade: `{{ __('Students') }}`. PHP: `__('Payment recorded.')`. Counts: `trans_choice(':count student|:count students', $n)`.
2. Placeholders, not concatenation: `__('Invoice :number paid', ['number' => $n])`.
3. Keys are the English sentence, written as the UI shows it (sentence case).
4. Add the key to **both** JSON files in the same commit. French must come from `GLOSSARY_EN_FR.md`.
5. Dates: `local_date($d, 'medium')`; money: `money($amount)`; numbers: `number_local()`. Never `->format('M j, Y')` in views.
6. Attribute strings too: `placeholder`, `title`, `aria-label`, `alt`.
7. Enums: `label()` returns `__("enums.{$enum}.{$case}")`.
8. JavaScript and Alpine: `t('…')`; no literal strings in `x-text`.
9. Leave room: French is ~20 % longer; buttons must wrap or truncate gracefully.
10. Names, emails, codes (admission numbers, invoice numbers) are never translated.

## 4. French style

- Vous form (« Enregistrez », « Vous n'avez pas… »).
- Typographic spaces before `: ; ? !` and inside « guillemets » (use non-breaking spaces ` `).
- Numbers `125 000`, decimals `12,5`, money `125 000 FCFA`, dates `5 nov. 2026`, 24-hour time `14 h 30` or `14:30` (choose `14:30` for tables).
- Capitalise only the first word in titles (« Frais de scolarité », not « Frais De Scolarité »).

## 6. Quality gates (CI)

1. `TranslationKeysTest`: same keys in EN and FR, no empty values.
2. `UntranslatedTextTest`: scans views for bare text nodes (allow-list for brand and codes).
3. Playwright `i18n.spec.ts`: 40 URLs × each role in French; fails on English sentinel words.
